# 黑洞吞吞（Hole It 網頁版）

仿《Hole it!》（Supersonic Studios）玩法的手機網頁遊戲：拖曳黑洞，只吃任務指定的物品，越吃越大，在時間內完成任務。

## 怎麼玩

- 按住螢幕拖曳 → 移動黑洞（電腦可用滑鼠拖曳或 WASD／方向鍵）
- 畫面上方是任務：每種物品要吃幾個
- 標「別吃」的東西（例如炸彈）吃到會扣時間，炸彈還會讓黑洞變小
- 主選單有「每日挑戰」（每天一關，首次過關 +100 金幣）、「商店」（用金幣買黑洞外框、吞噬特效，或 100 金幣轉一次扭蛋抽金幣／道具／限定造型）與「圖鑑」（吃過的物品都會收錄，每 10 種送 50 金幣）；連吃 25 個加 1 秒
- 開局加成：任務畫面可花金幣勾選「開局大一級」「多 15 秒」「目標指引箭頭」，只限這一局
- 道具：⏱ +15 秒、🧲 磁鐵（把任務物品吸過來）、🕳️ 暫時變大，用過關得到的金幣買
- 第 1～16 關照官方實機影片重做（任務照官方，限時改用模擬計算）；第 17 關之後自動生成：同一關裡東西分成好幾層尺寸，要一路升級才吃得到更大的；10 種主題、6 種整關擺法、多種關型（迷宮、追逐、旋轉盤、鑰匙迷宮、順序、縮圈、夜晚，每 10 關一個頭目）；越後面層數與數量越多。限時＝模擬玩家完成秒數 × 寬裕倍數（1.7 → 1.3）；進度與金幣存在瀏覽器裡

## 發版

```
node deploy.mjs "這次改了什麼"             # 版本號 +1、commit、推上 GitHub，Pages 約一分鐘後更新
node deploy.mjs "這次改了什麼" --netlify   # 同時發到舊的 Netlify 網址
```

## 在手機上玩

1. 電腦上雙擊 `start-server.bat`（需要已安裝 Python）
2. 手機連同一個 Wi-Fi，用瀏覽器開視窗裡顯示的 `http://192.168.x.x:8765`
3. 第一次連線若 Windows 跳出防火牆提示，請允許「私人網路」
4. 想要全螢幕：瀏覽器選單 →「加到主畫面」

要讓外面的人也能玩，把整個資料夾放到任何靜態網站空間即可（GitHub Pages、Netlify 等），不需要後端。

## 檔案結構

| 檔案 | 內容 |
|---|---|
| `index.html` / `css/style.css` | 畫面與 HUD |
| `js/objects.js` | 所有物件的低多邊形模型（程式產生，沒有外部素材） |
| `js/levels.js` | 地板、擺放圖樣（螺旋、圓環、馬賽克、金字塔、高塔）與關卡資料 |
| `js/game.js` | 黑洞、掉落與堆疊崩塌、相機、關卡流程 |
| `js/audio.js` | WebAudio 即時合成音效 |
| `js/vendor/three.min.js` | Three.js r149 |

新增關卡：在 `js/levels.js` 的 `LEVELS` 陣列加一筆，`build(F)` 裡用 `F.spiral / F.ring / F.rings / F.disc / F.rect / F.line / F.shape / F.pyramid / F.tower / F.scatter` 擺物件。

## 測試

網址加 `?level=N` 可直接開第 N 關（例如 `?level=18`），同時會解鎖到該關。
